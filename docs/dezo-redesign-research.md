## What makes a site impressive (principles only — never copy)

| Lens | Principle | DEZO application |
|---|---|---|
| First 3 seconds | Specific positioning + real visual proof | Full-bleed live project + **DEZO** + **BUILD. MARKET. GROW.** |
| Trust | Real work > invented metrics | Image-led case stories; host strip; no volume vanity |
| Typography | Serif display + quiet sans | Instrument Serif + DM Sans; brand overpowers headline |
| Case studies | Challenge → action → result | Featured work narrative blocks |
| Motion | Purposeful hierarchy | GSAP entrance, clip reveals, magnetic CTAs, engine stagger; respect reduced-motion |
| Conversion | One primary CTA | Start a Project repeated; secondary View Work / Lab |
| Credibility | Controlled vs uncontrolled promises | `/promise` DEZO Standard |
| Platform value | Useful tools, honest about limits | DEZO LAB analyst toolkit |
| Craft | Spacing, rules, sequence | Editorial rows, hairlines, no card grids in hero |
| Performance | Fast load is a signal | Lazy previews, webpack build, no WebGL spectacle |

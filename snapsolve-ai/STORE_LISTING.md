## Full description

SnapSolve is a Chrome study companion: capture a question from your screen, then get a clear answer you can learn from.

**Default = free LLM.** SnapSolve routes to OpenRouter free models out of the box. You can also connect Groq, Hugging Face, or run Ollama / LM Studio locally — no paid API required to start. Sample answers work offline.

**Connect every AI in Settings.** Sign in at the provider site, create an API key, and paste it under Connect AI:

OpenAI · Google Gemini · Anthropic Claude · OpenRouter · Groq · Mistral · DeepSeek · Together · Fireworks · Cerebras · Cohere · Hugging Face · Ollama · LM Studio · Custom OpenAI-compatible endpoints

**Free vs Pro**
- Free: free LLM hosts, sample mode, daily solve limit
- Pro: paid cloud providers, higher limits, second-model verification, custom endpoints

**Privacy-first**
- Capture only when you click — no background screen watching
- API keys stay in extension storage (encrypted at rest)
- Keys are never injected into websites
- Optional consent before sending text to hosted APIs

**Made for studying, not cheating.** Prefer explanations and practice over live graded exams.
